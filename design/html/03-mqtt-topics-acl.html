MOSQUITTO ACL
user msg-hub
topic readwrite orb/#

# every orb, scoped by its client id
pattern write orb/%c/hello
pattern write orb/%c/status
pattern write orb/%c/event
pattern read  orb/%c/config
pattern read  orb/%c/inbox
pattern read  orb/%c/led
pattern read  orb/%c/notice
topic   read  orb/all/#
Orbs share one "orb" login. %c pins each to topics under its own client id, so one orb can't write another's inbox.
